## Kodi / TV UX Skills

### 10-foot experience

- **Minimum 22px font size** for body text.
- **Thicker, substantial typefaces** with increased line spacing.
- **Wider character spacing** for better distance readability.
- **Roboto or similar sans-serif fonts** for labels and longer text.
- **Avoid decorative fonts** that become unreadable from across the room.
- **Test from 3+ meters** in different lighting conditions.

### Simplicity and visual hierarchy

- **Ruthless simplification** — interfaces must communicate clearly across the room.
- **Lean-back experience** — prioritize low cognitive load.
- **Generous white space** — the most powerful TV design tool at distance.
- **Large, clear content tiles** with minimal text overlay.
- **Consistent spacing patterns** and limited simultaneous choices.
- **Single primary purpose** per screen.
- **Visual hierarchy** — one explicit primary action per screen.

### Remote-control navigation

- **D-pad navigation** — only up/down/left/right/select movement.
- **Clear focus states** — instant visual feedback for the selected element.
- **Obvious visual distinction** — bold borders, color changes, scaling effects.
- **Predictable navigation paths** — logical movement patterns.
- **Accessible back button** — always returns without trapping the user.
- **Consistent spacing** — equal distances between focusable elements.

### Safe areas and overscan

- **TV screens do not display edge-to-edge** — overscan can cut off borders.
- **Use platform-safe margins** — keep critical UI away from the edges.
- **Test on actual televisions** — emulators do not replicate real behavior.
- **Keep key UI elements within safe boundaries**.
- **Use overscan zones only for decorative backgrounds**.
